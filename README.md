# Продуктовый помощник — автотесты (Sprint 9)

Учебный проект по автоматизации веб-тестирования сервиса **«Продуктовый помощник»**.  
Цель проекта - покрыть ключевые пользовательские сценарии автотестами на Selenium и настроить их запуск в CI/CD, включая запуск в связке с **Selenoid** и генерацию отчетов **Allure**.

---

## Покрытая функциональность

Реализованы автотесты для следующих сценариев:

1. **Создание аккаунта**
   - Нажать кнопку «Создать аккаунт».
   - Заполнить форму регистрации и отправить.
   - Проверить:
     - произошёл переход на страницу авторизации;
     - отображается форма авторизации.

2. **Авторизация**
   - Нажать кнопку «Войти».
   - Заполнить форму авторизации и отправить.
   - Проверить:
     - произошёл переход на главную страницу;
     - отображается кнопка «Выход».

3. **Создание рецепта**
   - Авторизоваться и перейти на таб «Создать рецепт».
   - Заполнить форму создания рецепта и отправить.
   - Особенность: ингредиент выбирается из списка — нужно начать вводить название,
     чтобы появился выпадающий список и выбрать опцию оттуда.
   - Проверить:
     - отображается карточка созданного рецепта;
     - название рецепта совпадает с введённым.
